Gmail Auto Organizer

Gmail Auto Organizer é uma automação de uso pessoal que mantém a Caixa de entrada organizada. Ela identifica mensagens que já foram lidas e que pertencem a marcadores previamente definidos e remove somente o rótulo INBOX, arquivando essas mensagens sem apagá-las.

Como funciona

A automação é executada periodicamente pelo GitHub Actions e usa a Gmail API com autorização OAuth concedida pelo próprio titular da conta. As mensagens continuam disponíveis em seus marcadores correspondentes.

A automação não exclui mensagens, não envia mensagens para a Lixeira e não remove os marcadores existentes.

Uso de dados do Google

O aplicativo usa o acesso ao Gmail exclusivamente para localizar mensagens que atendam às regras de organização e para remover o rótulo da Caixa de entrada. Ele não lê nem armazena o conteúdo dos e-mails ou anexos para outras finalidades.
