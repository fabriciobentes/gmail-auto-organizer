Política de Privacidade

Gmail Auto Organizer é uma automação de uso pessoal destinada a organizar uma conta Gmail autorizada pelo próprio titular.

Dados acessados

O aplicativo usa a Gmail API para consultar marcadores e identificar mensagens que estejam na Caixa de entrada, já tenham sido lidas e pertençam a marcadores previamente configurados. Para essas mensagens, a automação remove apenas o rótulo da Caixa de entrada.

Conteúdo das mensagens

A automação não utiliza o corpo dos e-mails nem anexos para sua finalidade. Ela trabalha com identificadores de mensagens, estado de leitura e marcadores necessários para executar a regra de organização.

Armazenamento e compartilhamento

O token OAuth é armazenado como segredo criptografado do GitHub Actions. O aplicativo não vende dados, não usa dados para publicidade e não compartilha dados do Gmail com terceiros para finalidades independentes da execução da automação.

Uso limitado

Os dados obtidos por meio das APIs do Google são usados somente para fornecer a funcionalidade descrita nesta página, de acordo com as permissões concedidas pelo usuário.

Revogação

O titular pode interromper a automação removendo o segredo OAuth do repositório, desativando o workflow ou revogando o acesso do aplicativo nas configurações da Conta Google.
